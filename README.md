# Pathfinder: Frontier Substrate
> “Identify the rails before the destinations.”

Pathfinder is a sovereign evidence architecture for mapping the structural dependencies of frontier technologies. It separates doctrine, governance, evidence, graph analytics, and operator decision-making to construct evidence-bound infrastructure universes across quantum computing, fusion energy, AI infrastructure, semiconductors, and future deep-technology domains. It is **not** a chatbot, an autonomous executor, or a speculative quantum-research tool. It keeps final decision-making authority strictly in the hands of the **Operator**.

---

## 🏛️ System Core Architecture

Pathfinder is designed with a strict division of responsibilities across separate functional layers to prevent the collapse of analytical integrity.

```
                                  ┌────────────────────────┐
                                  │      OPERATOR          │ (Final Authority)
                                  └───────────▲────────────┘
                                              │ Approved Findings
                                  ┌───────────┴────────────┐
                                  │       OCTAGON          │ (Governance & Safety)
                                  └───────────▲────────────┘
                                              │ High-Integrity Query / Routing
                                  ┌───────────┴────────────┐
                                  │       CLAUDIA          │ (Routing & Orchestration)
                                  └───────────┬────────────┘
                                              │
              ┌───────────────────────────────┼───────────────────────────────┐
              ▼                               ▼                               ▼
  ┌───────────────────────┐       ┌───────────────────────┐       ┌───────────────────────┐
  │        HERMES         │       │        AETHER         │       │  ANALYTICAL ENGINES   │
  ├───────────────────────┤       ├───────────────────────┤       ├───────────────────────┤
  │ Graph Traversal,      │       │ Immutable Datasets,   │       │ Centrality Computing, │
  │ Discover & Retrieval  │       │ Document Repositories │       │ RAPIDS, Custom Models │
  └───────────────────────┘       └───────────────────────┘       └───────────────────────┘
```

### 1. OPERATOR
*   **Role:** The sovereign and final human decision-maker.
*   **Doctrine:** No finding, recommendation, or graph metric constitutes authority without Operator review and approval. Pathfinder does not execute transactions, publish findings, or deploy systems autonomously.

### 2. OCTAGON
*   **Role:** Governance, permissions, safety validation, and data custody.
*   **Doctrine:** Enforces "fails-closed" security, validates user credentials, prevents data leaks, and checks evidence bindings before any data moves into persistent stores.

### 3. CLAUDIA
*   **Role:** Routing, decomposition, and orchestration.
*   **Doctrine:** Claudia parses Operator-submitted queries or missions and decomposes them into structured, evidence-bound pipelines. She routes operational calls to Hermes, Aether, or the Analytical Engines without overstepping her routing role or acting as an oracle.

### 4. HERMES
*   **Role:** Information traversal, graph discovery, and source relation tracking.
*   **Doctrine:** Traverses structured nodes and edges in the evidence graph, discovering new connections and providing retrieval indices.

### 5. AETHER
*   **Role:** Immutable document store, datasets, and knowledge bases.
*   **Doctrine:** Serves as the bedrock repository for regulatory filings, official registers, peer-reviewed papers, and audited technical logs.

## 📊 Core Concepts & Methodologies

### ⚡ RAPIDS (Row-based Attributes Portfolio and Influence Decisive Score)
The evaluation scorecard used to gauge each mapped enabler across seven core pillars:
1.  **Cash Flow (CF):** Operational viability and capital runway.
2.  **Ecosystem Position (EP):** Systemic critical-path position.
3.  **Capital Intensity (CI):** Funding requirements and CapEx exposure.
4.  **Government Contracts (GC):** Sovereign demand and backing.
5.  **AI Integration (AI):** Machine learning capability and utilization.
6.  **Supply Chain Importance (SC):** Upstream and downstream reliance.
7.  **Scientific Leadership (SL):** IP portfolio, expert density, and breakthrough history.

### 🌉 Crystal Bridge (Ecosystem Linkage)
The physical interface and logical substrate bridging separate deep-tech sectors (e.g., how the cryogenics rail in quantum computing matches high-temperature superconducting cooling systems in fusion energy).

### 🕸️ Evidence Graphs & Centrality Index
Nodes represent technology providers, enablers, and organizations, while edges represent verified industrial dependencies. Centrality metrics are calculated as live, objective measures of current evidence graph density, not as marketing proxies:
*   **PageRank (PR):** Calculates systemic recursive importance and prestige.
*   **Betweenness Centrality (BC):** Detects bottleneck organizations on the shortest dependency paths.
*   **Degree Centrality (DC):** Counts direct inbound and outbound dependencies.

### 🚀 Sector Universes
Modular, isolated data boundaries mapped within the system:
*   **Quantum Universe:** Focuses on sub-Kelvin computing, materials, silicon fabrication, photonics, and test instrumentation.
*   **Fusion Universe:** Focuses on high-temperature superconducting (HTS) magnets, cryogenic systems, computationally simulated plasma digital twins, and vacuum boundaries.

### 🏷️ Observation vs. Inference Labels
To maintain high-integrity analytical standards, data points must be explicitly categorized:
*   **Observation:** Verified, documented physical state or historical event (e.g., "Company has a standard operational EUV lithography machine").
*   **Inference:** Extrapolated or modeled projection based on observations (e.g., "Company is likely to scale qubit counts by 2x next year").

### 🚦 Transaction-State Gates (Corporate Action State-Machine)
For companies undergoing corporate actions (e.g., SPAC mergers like General Fusion `GFUZ` and Trump Media `DJT`), exposure state is strictly validated across sequential gates:
```
[ RUMOURED ] ──► [ ANNOUNCED ] ──► [ FILED ] ──► [ APPROVED ] ──► [ CLOSED ] ──► [ TRADING_LIVE ]
```
*   **GFUZ:** Status is **CLOSED & TRADING_LIVE** (Pure-play active fusion exposure).
*   **DJT:** Status is **ANNOUNCED** (Prospective transaction, contingent exposure; operationally remains a media company until closure).

### 🗃️ Isolated-Node Backlog
Nodes that are known to exist but have zero verified incoming or outgoing edges. They remain clearly visible in dashboards to identify analytical blindspots and drive subsequent evidence sweeps.

## ⚠️ Stop Conditions

Claudia and the Pathfinder Agent Guild will instantly halt operations and request Operator input when:
1.  A claim lacks complete provenance bindings (`source_id` + `evidence_id` empty).
2.  Primary sources conflict on a material fact (e.g., transaction closure status).
3.  A transaction state gate is unverified or lacks official regulatory filing evidence.
4.  A relationship is modeled as a verified edge without direct provenance.
